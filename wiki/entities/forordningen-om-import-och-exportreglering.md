## Sammanfattning

Förordning (1997:969) är det centrala svenska regelverket för import- och exportlicensiering. Den definierar vilka varor som kräver tillstånd, utpekar licensmyndigheter (Statens jordbruksverk för jordbruks-/livsmedelsvaror, Kommerskollegium för övriga varor), och säkerställer överensstämmelse med EU:s import- och exportförordningar. Förordningen är en verkställighetsförordning som överför EU:s och regeringens reglering till praktisk licensadministration.

## Befogenheter

Förordningen ger följande befogenheter:

1. **Licensmyndigheterna** (Jordbruksverk och Kommerskollegium) får:
   - Meddela föreskrifter för licensverkställighet (7 §)
   - Samråda med Tullverket vid föreskriftsmeddelande
   - Utföra uppgifter som EU-medlemsstat kräver för import/export

2. **Regeringen** kan:
   - Bestämma vilka varor som kräver licensering
   - Bemyndiga licensmyndigheter att meddela föreskrifter

3. **Tullverket** samverkar med licensmyndigheterna vid kontrollfunktioner.

## Straffbestämmelser

Denna förordning innehåller inga självständiga straffbestämmelser. Straff för olovlig import eller export regleras genom [[smugglingslagen]] (2000:1225), som kriminaliserar import/export utan erforderlig licens.

## Nyckelbestämmelser

| Bestämmelse | Innehål |
|---|---|
| **1 §** | Tillämpningsområde: varor som kräver licens enligt EU, regeringen eller licensmyndigheter |
| **2-3 §§** | Licensmyndigheter: Jordbruksverk (jordbruks-/livsmedelsvaror), Kommerskollegium (övriga); Kommerskollegium för sanktionsvaror |
| **5 §** | Ursprung bestäms enligt EU:s tullkodex |
| **7 §** | Licensmyndigheterna får meddela föreskrifter efter samråd med Tullverket |
| **8 §** | Straff för olovlig import/export enligt [[smugglingslagen]] |
| **Bilaga 1** | Undantagna varor/lagstiftning (kärnkraft, krigsmateriel, dubbla användningsområden, valutakontroll) |
| **Bilaga 2** | Jordbruksvaror som Jordbruksverk ansvarar för (KN-kapitel 1-24, 31 + specifika KN-nummer) |

## Praktisk tillämpning

### Typiska situationer

1. **Import av jordbrutsvaror** — Importör kontaktar [[statens-jordbruksverk]] för importlicens innan varorna förs in. Licensverket samverkar med [[tullverket]] för tullklarering.

2. **Export av licensreglerad vara** — Exportör ansöker hos lämplig licensmyndighet (beroende på varuslag) före export. Tullverket kontrollerar att licens föreligger vid utgången.

3. **Sanktionerad handel** — Om varor är föremål för EU-sanktioner hanteras licensering av [[kommerskollegium]]. Utan licens utgör importen/exporten både brott enligt denna förordning och möjlig smugling.

4. **Gränskontroll** — [[tullverket]] kan stanna verdade för att kontrollera att erforderlig licens föreligger. Avsaknad av licens för licensreglerad vara kan föranleda beslagtande.

### Licensmyndigheternas roller

| Myndighet | Ansvar |
|---|---|
| **Statens jordbruksverk** | Import/export av jordbruks- och livsmedelsvaror (bilaga 2); ansökan, tillståndsprövning, övervakning |
| **Kommerskollegium** | Övriga varor; sanktionsreglerade varor; ansökan, tillståndsprövning, övervakning |
| **Tullverket** | Tullkontroll, verifikation av licensförekomst, beslagtag av varor utan licens |

### Relation till EU-reglering

Förordningen implementerar EU:s tullkodex och andra EU-förordningar om import/export. Svenska licenser måste stämma överens med EU-ramverket. Ändringar i EU-reglering kan medföra ändringar i denna förordning.
