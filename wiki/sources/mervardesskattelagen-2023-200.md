# Mervärdesskattelag (2023:200)

> [!note] Partiell ingest
> Lagen är 7 749 rader och 24 kapitel. Denna sammanfattning fokuserar på **tullrelevanta delar**: import som beskattningsbar transaktion, skatteupplag/tullager, betalningsskyldighet vid import, distansförsäljning (IOSS) och den särskilda importordningen.

## Översikt

Mervärdesskattelagen (ML) är Sveriges centrala momslagstiftning, som trädde i kraft 1 juli 2023 och ersatte den äldre mervärdesskattelagen (1994:200). Lagen implementerar EU:s mervärdesskattedirektiv (2006/112/EG) och är uppdelad i 24 kapitel.

ML är en av de viktigaste skattelagarna vid import — mervärdesskatt tas ut vid import av varor till Sverige utöver eventuell tull och punktskatt.

## Tullrelevanta nyckelkapitel

### 5 kap. — Import som beskattningsbar transaktion (37 §)

Import av varor är en beskattningsbar transaktion. Med import avses att en icke-unionsvara förs in till Sverige. Även varor som lämnar en frizon, tullager, tillfälligt lagringsanläggning eller tullförfaranden (transitering, passiv förädling, tillfällig införsel) utgör import.

### 6 kap. 66-68 §§ — Platsen för import

- **66 §**: Import anses gjord i Sverige om varan finns här när den förs in i EU.
- **67 §**: Om varan vid införseln till EU hänförs till tillfällig lagring, tullager, frizon eller tullförfarande — anses importen gjord i det EU-land där varan lämnar dessa arrangemang.
- **68 §**: Om varan befinner sig i tillfällig lagring etc. vid införseln och först lämnar dessa i Sverige — anses importen gjord här.

### 7 kap. — Beskattningsgrundande händelse vid import

- **13 §**: Den beskattningsgrundande händelsen inträffar och skatten ska redovisas vid den tidpunkt då tullskuld uppkommer (eller skulle ha uppkommit om varan varit belagd med tull).
- Särskilda regler för varor som lämnar tullförfaranden (14-15 §§).

### 8 kap. — Beskattningsunderlag vid import

- **24 §**: Beskattningsunderlaget vid import är tullvärdet + tull + punktskatter.
- **25-27 §§**: Bikostnader (provision, förpackning, transport, försäkring) till den första bestämmelseorten i Sverige ska inkluderas.

### 9 kap. — Skattesatser

| Skattesats | Tillämpning |
|-----------|-------------|
| 25 % | Standardsats |
| 12 % | Livsmedel, restaurangtjänster, hotell |
| 6 % | Böcker, tidningar, persontransport, kultur, sport |

### 11 kap. — Varor i vissa lager

Centralt kapitel för tullverksamhet:

- **Skatteupplag** (2-3 §§): Definieras som godkända lager för 27 varugrupper (metaller, spannmål, oljor, kemikalier m.m.) med KN-nummer. Kopplat till energiskattelagen och alkoholskattelagen.
- **Undantag** (4-5 §§): Leverans, unionsinternt förvärv och import av varor avsedda för skatteupplag är **undantagna från skatteplikt** — likaså varor i tillfällig lagring, tullager eller frizon.
- **Utlösningsmekanism** (6-8 §§): När varan **lämnar** skatteupplaget/tullagret/frizonen ska moms tas ut. Beskattningsunderlaget baseras på sista leveransvärdet + tjänster.
- **Godkännande** (10-11 §§): Skatteverket godkänner upplagshavare och skatteupplag.

### 16 kap. 18-22 §§ — Betalningsskyldig vid import

- **18 §**: Den som är skyldig att betala tull är också skyldig att betala moms. Om varan är tullfri men importmomspliktig — den som skulle ha varit tullskyldig.
- **19 §**: Vid otillåten införsel — den som orsakat tullskulden.
- **20-22 §§**: Särskilda fall: varor från tillfällig lagring/tullförfarande, samt varor med villkorlig tullbefrielse.

### 22 kap. — Distansförsäljning och IOSS

- **Import One-Stop Shop (IOSS)**: Särskild ordning för distansförsäljning av varor importerade från tredjeland med värde ≤150 euro. Leverantören registrerar sig och redovisar moms via IOSS istället för att köparen betalar importmoms.
- **Elektroniska gränssnitt** (6-8 §§): Plattformar som underlättar distansförsäljning behandlas som om de själva levererat varorna → betalningsskyldiga för moms.

### 23 kap. — Särskild ordning vid import

Förenklad ordning för lågvärdiga importförsändelser (≤150 euro):
- Anmälaren (t.ex. postombud/speditör) tar ut moms direkt från mottagaren.
- Månatlig inbetalning och sammanställning till Tullverket.
- Dokumentationsskyldighet i 7 år.
- 150-euro-gränsen kopplas till tullbefrielsegränsen (förordningen om tullbefrielse, art. 23).
